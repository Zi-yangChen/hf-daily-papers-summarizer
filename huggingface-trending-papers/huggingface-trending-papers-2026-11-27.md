1. **具身智能与仿真自动化（Real-to-Sim & Synthetics）重塑机器人学习**：研究重心正从单纯的算法优化转移到构建闭环实验环境，通过代码 Agent 与生成式渲染自动合成高质量物理场景与数据，突破现实数据采集的物理瓶颈。

3. **多模态与 Agent 推理范式的深化变革**：无论是在无视频数据下的视频编辑、异步记忆驱动的超长视频生成，还是利用代码 Agent 取代原生视频模型进行精确视觉逻辑推理，多模态 AI 正向更具结构化和可解释性的推理方向快速演进。

#### 2. Mixture-of-Loops Transformer
* **论文链接**：https://huggingface.co/papers/2611.34923
* **研究机构/作者**：未在数据集中提供具体作者信息
* **核心痛点与创新点**：
  现有的大语言模型在扩展能力时通常盲目堆叠层数，这带来了巨大的显存开销与计算资源浪费。为解决这一问题，论文提出了 Mixture-of-Loops (MoL) Transformer 这一全新的网络架构。该架构创新性地将混合专家（MoE）的动态路由思想与循环神经网络（RNN）的参数重用机制融为一体。在计算过程中，输入 Token 会由路由网络动态分发给不同的计算循环（Loop）模块，并在其中进行多次迭代。这种设计使得模型能够在不增加参数量的前提下，通过增加 Token 的计算深度大幅提升表达能力。同时，MoL 避免了传统 MoE 架构因为参数庞大而导致的显存爆炸问题。实验验证表明，MoL 在长文本理解和复杂推理任务中，在计算效率与模型性能之间取得了极佳的平衡。
* **潜在影响力**：开辟了大模型架构设计的新途径，重新证明了参数重用（Weight Sharing）与动态路由结合的庞大潜力，对端侧部署大模型极具借鉴意义。

#### 4. HOG-WAM: Improving Visual Robustness through Future Gradient Prediction

* **潜在影响力**：为实现高鲁棒性的计算机视觉系统以及防对抗攻击训练提供了全新范式，对自动驾驶与安全敏感型视觉场景至关重要。

#### 5. High-Fidelity Image Matting with Pixel-Space Diffusion Transformers

* **潜在影响力**：极大地提升了影视级特效抠图和图像后期合成的画质质感，标志着像素空间 Diffusion 架构在超精细视觉任务中的重大突破。

#### 8. RoboEvo^2: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution

  机器人强化学习中的策略（Policy）自改进往往受制于人工设计的评估与训练约束（Harness），容易陷入局部最优。论文推出了 RoboEvo^2 框架，实现了“策略与评估约束协同进化”（Harness-Policy Co-Evolution）的递归自改进机制。在该框架中，策略 Agent 负责在复杂任务中提升操作技能，而 Harness Agent 负责动态调整任务难度与评价标准。当策略技能提升时，Harness 会自动引入更具挑战性的环境扰动与严苛指标，打破策略的舒适区。反之，当策略遭遇瓶颈时，Harness 会动态调整奖励函数以提供更清晰的探索信号。这种双向促进的协同进化机制使得机器人能够进行持续、自主的技能迭代与扩展。实验证明，RoboEvo^2 显著提升了机器人策略在面对未见过操控任务时的自适应能力。
* **潜在影响力**：赋予了机器人无干预自主进化的可能性，是通用机器人（AGI in Robotics）实现终身学习与自我迭代的重要尝试。

#### 9. LoopTitan: What Does Parameter Revisit Buy a Mixture-of-Experts?
* **论文链接**：https://huggingface.co/papers/2611.34821
* **研究机构/作者**：未在数据集中提供具体作者信息
* **核心痛点与创新点**：
  混合专家（MoE）模型虽然拥有巨大的总参数量，但每个 Token 在单次前向传播中仅能访问极少数专家且无法重复使用。针对这一局限，论文提出了 LoopTitan 架构，专门探讨在 MoE 中引入“参数重访”（Parameter Revisit）机制的收益。该架构允许输入 Token 在单次前向传递中根据路由指令多次循环访问特定的专家模块。这种设计在显存占用保持不变的前提下，通过增加测试时间的计算量（Test-time compute）显著提升了推理深度。研究发现，参数重访能够极大地增强 MoE 模型在复杂数学推导与长链条逻辑推理中的泛化性能。论文还探讨了如何优化循环路由策略，以最小化计算延迟并提高硬件利用效率。该工作证明了利用循环计算扩展 MoE 能力是一种相较于单纯增大模型体积更高效的路径。
* **潜在影响力**：为大模型推测执行、显存受限情况下的计算扩展（Test-Time Scaling）提供了全新视点与工程范式。

#### 10. When Every Rollout Fails: Splicing Learner-Conditioned Options into Long-Horizon Agent RL
* **论文链接**：https://huggingface.co/papers/2611.34777
* **研究机构/作者**：未在数据集中提供具体作者信息
* **核心痛点与创新点**：
  在长跨度（Long-Horizon）强化学习中，由于探索空间巨大且奖励极其稀疏，智能体在前期的每一次尝试（Rollout）往往都以失败告终。针对这种全面失败的“探索困境”，论文提出了一种“学习者条件化选项拼接”（Option Splicing）算法。该算法从智能体大量失败的历史轨迹中挖掘并提取出有价值的子动作结构（Options）。随后，算法将这些子动作段进行动态剪辑与重组拼接，构建出通往远端目标的结构化路径。这使得智能体能够跨越无有效奖励的广阔空间，迅速触及极难到达的奖励状态。拼接后的选项还能根据智能体当前的学习状态进行自适应调整，防止策略陷入死循环。实验表明，该方法在多种极度稀疏奖励的长跨度复杂 Agent 任务中显著提升了训练成功率。
* **潜在影响力**：为复杂长决策 Agent（如软件工程自动化、复杂游戏 AI）解决“冷启动”与极端稀疏奖励问题提供了坚实的方法论支持。

#### 11. Collect for Coverage, Replay with Evidence: Adaptive and Efficient On-Policy Distillation for Long-Horizon Agents

* **潜在影响力**：大幅降低了长序列复杂 Agent 的模型蒸馏与轻量化成本，对高计算开销场景下的模型压缩具有普遍借鉴意义。

#### 18. A Mesh for Every Moment
