#### **[AdvSim2Real : Training Web Agents Against Adaptive Prompt Injection in a Web World Model]** (附带论文链接: [https://huggingface.co/papers/2610.08773](https://huggingface.co/papers/2610.08773))
- **研究机构/作者**：请参考论文页面
- **核心痛点与创新点**：传统的 Web 智能体在处理真实网络环境时，极易受到网页中嵌入的恶意提示词注入（Prompt Injection）攻击。由于现实攻击往往具有自适应性，静态的防御手段极易失效。为此，本文提出了一种“模拟到真实”（Sim2Real）的防御训练框架。该框架在一个高度逼真的 Web 世界模型（Web World Model）中，部署了一个对抗性的“攻击生成器”。在训练过程中，攻击生成器会根据智能体的行为动态调整注入策略，而智能体则通过对抗强化学习来学习规避并识别这些陷阱。这种动态演化的攻防演练，显著提升了智能体对未见过的自适应攻击的鲁棒性。
- **潜在影响力**：为网络自动化智能体的安全部署提供了全新的安全范式，推动智能体防御技术从“被动打补丁”走向“主动模拟对抗”。

#### **[CtrlCache: Accelerating Interactive Video World Models with Control-Aware Caching]** (附带论文链接: [https://huggingface.co/papers/2610.08777](https://huggingface.co/papers/2610.08777))

#### **[UNREAL: Unifying Retrieval and Long-Context with a Single Model]** (附带论文链接: [https://huggingface.co/papers/2610.08463](https://huggingface.co/papers/2610.08463))

#### **[Rethinking Cross-Tokenizer On-Policy Distillation: From Alignment Coverage to Supervision Reliability]** (附带论文链接: [https://huggingface.co/papers/2610.08448](https://huggingface.co/papers/2610.08448))
- **研究机构/作者**：请参考论文页面（注：该论文点赞数高达 153，是今日最受关注的研究之一）
- **核心痛点与创新点**：在知识蒸馏中，当教师模型和学生模型使用完全不同的分词器（Tokenizer）时，由于它们的 Token 边界无法直接对应，很难将教师的高质量概率分布无损地传递给学生。本文对此进行了彻底的反思。作者指出，传统的“对齐覆盖”方法强行映射会导致严重的语义漂移。他们提出了一种名为“监督可靠性（Supervision Reliability）”的全新数学框架。该框架不进行机械的 Token 级别对齐，而是通过在概率概率空间上建立严谨的连续语义映射，把教师模型的软标签分布平滑、精准地平移到学生词表中，确保梯度下降的稳定性。
- **潜在影响力**：极大提升了从小模型向大模型蒸馏的效率与最终精度，使得开发者能够以极低成本打造出逼近 GPT-4 级表现的轻量化开源模型。

#### **[NeMo-DCR: Bit-Exact Delta-Compressed Refit for Scalable Agentic RL at Trillion-Parameter Scale]** (附带论文链接: [https://huggingface.co/papers/2610.08430](https://huggingface.co/papers/2610.08430))
- **研究机构/作者**：请参考论文页面（可能是 NVIDIA 相关团队）
- **核心痛点与创新点**：对万亿参数（Trillion-parameter）级别的巨型大模型实施强化学习训练时，分布式集群间高频、海量的权重参数同步会带来极其可怕的网络带宽瓶颈。NeMo-DCR 引入了一种名为“位无损增量压缩重拟合”（Bit-Exact Delta-Compressed Refit）的技术。在分布式强化学习的参数分发阶段，该技术不直接传输完整模型或庞大的梯度，而是通过高度定制的、保证位精度完全一致的算法，计算出权重微小的“增量（Delta）”并对其进行极限压缩后再进行网络传输。这种无损压缩方法在不牺牲任何训练精度的前提下，减少了数倍的集群数据通信量。
- **潜在影响力**：解决了超大规模多智能体系统在进行在线强化学习时的物理通信瓶颈，让普通云端架构训练超巨型智能体模型成为可能。
