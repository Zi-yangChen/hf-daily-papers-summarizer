1. **具身智能与物理世界建模成为绝对核心**：从高赞论文来看，研究者们正致力于让模型超越纯文本与静态图像，通过融入物理动态表征（如 PDRVLA）与内部“世界想象”（如 ThinkWorld），实现物理规律的自主理解与精准动作生成。

#### 1. [PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations](https://huggingface.co/papers/2610.37381)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  传统的视觉-语言-动作（VLA）模型在机器人操控任务中，通常仅将视觉作为静态几何特征输入，缺乏对物理世界动态规律（如重力、碰撞、摩擦力和刚度）的深刻理解。这导致机器人面对未见过的复杂物理交互时，动作泛化性与鲁棒性极差。本文提出了 **PDRVLA** 架构，将物理动态表征（Physical Dynamics Representations）显式地注入到 VLA 模型中。模型引入了动态预测模块，能够在生成动作指令前隐式或显式地预测物体的物理演进状态。此外，结合多模态对比学习，将物理规律与语言指令、视觉表征进行深层对齐。实验表明，PDRVLA 在多种高难度操控任务中成功率显著提升，且对物理属性突变具备极强的适应力。
* **潜在影响力**：
  为具身智能接入“物理世界模型”提供了全新的实现路径，将显著推动通用机器人物理交互能力在真实复杂场景中的落地。

#### 2. [Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?](https://huggingface.co/papers/2610.37662)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  离散 Token 化（Discrete Tokenization）在连续视觉信号与类 LLM 离散架构之间建立了桥梁，但业界长期质疑其是否造成了不可逆的语义信息丢失。本文对“离散 Token 能否作为视觉信号的语义无损表征”这一根本问题展开了深入的理论与实验探究。作者系统分析了编码器码本大小、重建损失与下游高级语义任务（如细粒度分类、目标检测、语义分割）表现之间的对应关系。研究发现，当码本容量与几何/语义空间对齐达到特定临界点时，离散 Token 在语义表达上可以实现接近“无损”的效果。论文据此提出了一种优化离散表征语义保留的新方法，有效兼顾了高压缩率与语义完整性。
* **潜在影响力**：
  解答了自回归视觉生成与多模态大模型在离散化视觉表征上的底层理论疑虑，为下一代统一离散多模态大模型的发展奠定了坚实基础。

#### 3. [CodeCap-Bench: Can Code Serve as a Good Video Caption?](https://huggingface.co/papers/2610.37341)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  传统自然语言文本在描述视频时，往往存在时序模糊、空间定位不准以及复杂逻辑关系难以精确表达的问题。为了探索更加结构化和无歧义的视频描述范式，本文提出了 **CodeCap-Bench**，首次评估将“代码”作为视频描述介质的可行性与优越性。代码能够自然地通过条件语句、循环和函数调用来表达复杂的时间顺序、空间变换和因果关系。研究构建了多维度的评估基准，测试 LLM/VLM 将视频转换为结构化代码以及从代码理解视频的能力。实验证明，代码化描述不仅显著提升了逻辑密集型视频分析的准确率，还为视频理解开辟了可执行的符号化接口。
* **潜在影响力**：
  重新定义了视频理解与表征的范式，代码作为中间介质将极大地促进精细化视频生成、视频编辑以及复杂视频推理任务的发展。

#### 4. [ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning](https://huggingface.co/papers/2610.37666)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  当前大语言模型在处理涉及物理或动态环境变化的推理任务时，往往依靠纯文本的“思维链”（Chain-of-Thought），难以准确预测状态演变过程。为了解决这个问题，本文提出了 **ThinkWorld** 机制，引入“世界想象”（World Imagination）来增强动态思维链（Chain-of-Dynamics）推理。模型在每一步推理中，不仅生成文本推导，还会激活内部的动态场景预测器，显式或隐式地构建环境状态变化的精神图像。通过在“想象空间”中模拟动作反馈，模型能够及时修正推理偏差并探索更合理的解决方案。大量实验验证表明，ThinkWorld 在复杂的物理推理、棋盘游戏及动态规划任务中，思维链路的准确性与成功率大幅领先传统 CoT。
* **潜在影响力**：
  将物理世界模型的“想象力”融于逻辑推理，打破了纯文本思维链的局限，是迈向更高阶通用人工智能（AGI）逻辑推理的重要探索。

#### 5. [Zooming without Zooming v2: From Seeing Details to Connecting Evidence for Generalizable Multimodal Perception](https://huggingface.co/papers/2610.37037)

* **核心痛点与创新点**：
  传统多模态模型在处理超高分辨率图像或微小细节时，往往依赖昂贵的图像裁剪放大（Cropping/Zooming）机制，计算开销极大且容易割裂局部与全局的语义关联。本文推出了 **Zooming without Zooming v2**，提出了一种从“查看细节”升级为“关联证据”的通用多模态感知框架。该方法无需显式改变图像分辨率或引入多次输入放大，而是通过注意力机制的证据关联与跨尺度特征融合来捕捉局部细粒度信息。模型能够在保持全局上下文的同时，精准聚焦并连接分布式证据链，高效解决细粒度视觉问答与图表分析问题。实验结果表明，该算法在多种高分辨多模态基准测试中，既大幅节省了计算资源，又取得了领先的泛化感知性能。
* **潜在影响力**：
  为高分辨率视觉多模态大模型（VLM）提供了一种高效、高泛化性的感知新方案，极大地优化了算力与显存开销。

#### 6. [Channel Selection for Mixture-of-Experts Decoding Needs No Calibration Data](https://huggingface.co/papers/2610.37386)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  混合专家模型（MoE）在解码推理时虽然激活参数较少，但其高内存带宽占用和复杂的通道选择极大地限制了推理吞吐量，且现有剪枝/通道选择方法通常依赖大量的校准数据。本文提出了一种全新的“零校准数据”MoE 通道选择解码技术。作者发现 MoE 专家权重和激活分布内部存在不依赖具体输入的几何内在结构，可以通过无监督的代数特征提取直接确定冗余通道。通过在推理阶段动态抑制无关通道，该方法大幅降低了数据传输与计算延迟，且全程无需任何额外的测试或校准数据集。实验表明，该方法在保持模型固有性能几乎无损的同时，实现了显著的解码加速和显存占用降低。
* **潜在影响力**：
  大幅降低了 MoE 模型部署与推理加速的门槛，推动了高参数量 MoE 大模型在边缘侧和生产环境中的高效落地。

#### 7. [EmbeddingGemma 2: Unified and Efficient Multimodal Representations](https://huggingface.co/papers/2610.37364)

* **核心痛点与创新点**：
  现有的向量嵌入（Embedding）模型往往独立针对文本或图像进行设计，缺乏高性能且统一的多模态通用表征模型，且推理开销居高不下。本文推出了 **EmbeddingGemma 2** 模型，旨在提供轻量、统一且高效的多模态向量表征。该模型基于 Gemma 2 架构，通过创新的对比学习与多任务跨模态对齐目标，将文本、图像甚至代码统一映射到同一个高维语义空间。模型设计注重计算效率，支持灵活的向量维度裁剪（Matryoshka Representation Learning），以适应不同硬件约束。基准测试显示，EmbeddingGemma 2 在多模态检索、跨模态分类和 RAG（检索增强生成）任务中均取得了优异的综合表现。
* **潜在影响力**：
  为多模态搜索、跨模态推荐及多模态 RAG 系统提供了高性能的开源基础设施。

#### 8. [EnvSched: Environment-Aware Scheduling for Rollout-Efficient Agent Reinforcement Learning](https://huggingface.co/papers/2610.37609)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  基于强化学习（RL）训练智能体（Agent）时，在复杂异构环境中进行轨迹采样（Rollout）往往占用大量的计算资源与时间，造成严重的技术瓶颈。本文提出了 **EnvSched**，一种环境感知的调度框架，用于提升 Agent 强化学习中的 Rollout 效率。该框架动态分析不同智能体交互环境的复杂度、响应延迟和梯度贡献度，实现对算力资源的智能弹性分配。通过优先调度信息增益大、反馈速度均衡的环境轨迹，减少了集群等待时间（Straggler Problem）。实验证明，EnvSched 在多种智能体交互场景中实现了数倍的 Rollout 吞吐量提升，显著缩短了 Agent RL 的训练周期。
* **潜在影响力**：
  直击大模型 Agent 强化学习训练中的工程效能痛点，推动了大规模分布式 Agent 强化学习的加速发展。

#### 9. [Can LLMs Uncover Hidden Physical Laws through Free Exploration?](https://huggingface.co/papers/2610.37649)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  大语言模型在已知物理知识问答上表现出色，但它们能否像科学家一样，通过自主的“自由探索”发现隐藏的物理规律仍未可知。本文对此问题展开了系统性研究，搭建了允许 LLM 智能体通过主动设计实验、收集数据和假设检验来探索物理世界的虚拟环境。模型需要在没有任何先验方程提示的前提下，从零交互数据中拟合并归纳出物理定律（如守恒定律、碰撞运动等）。研究发现，配合科学假设生成提示和符号回归工具时，LLM 表现出初步的科学发现能力，但在处理非线性复杂交互时容易陷于局部先验偏见。论文总结了当前 LLM 在自主科学探索方面的局限，并提出了改进的探索范式。
* **潜在影响力**：
  探索了 AI for Science（AI 科学研究）的前沿边界，为利用大模型实现自动化科学发现提供了极具价值的评估基准与方法论。

#### 10. [Your Policy Is Secretly a Harness: The Decision Geometry of Agent Interfaces](https://huggingface.co/papers/2610.37255)
* **研究机构/作者**：*未在给出的数据集中显式提供*
* **核心痛点与创新点**：
  在 AI Agent 的设计中，业界通常将成功归因于策略模型（Policy）本身的强大，而忽视了交互接口（Interface/Harness）对决策过程的隐性塑造。本文从“决策几何学”（Decision Geometry）的角度深入揭示了 Agent 接口与策略模型之间的深层关联。研究发现，接口设计（如 Prompt 模板、动作空间变形、状态流切片）实际上是在给策略模型的决策空间施加一种强的几何约束，甚至在很大程度上决定了任务的上限。论文通过严格的理论推导与实验证明，许多看似是策略改进带来的收益，本质上是由接口带来的“套具效应”（Harness Effect）。为此，作者提出了优化接口决策几何的通用原则，以最大限度释放策略模型的原始潜力。
* **潜在影响力**：
  重新审视了 Agent 架构的设计范式，提醒研究者在开发智能体时需更加系统严密地对待接口工程与策略优化的解耦。
