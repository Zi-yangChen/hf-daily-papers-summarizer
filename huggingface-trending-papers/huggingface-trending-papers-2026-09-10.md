#### **1. [NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness]** 
* **论文链接**: https://huggingface.co/papers/2609.08183
* **研究机构/作者**: NeoHorse 研究团队
* **核心痛点与创新点**：
  痛点在于当前的 AI 系统在达到一定性能瓶颈后，难以在没有人类高质量新数据的情况下继续提升，且传统的自我改进方法容易陷入局部最优和模式崩溃。本论文提出了 NeoHorse-1，探索了一种通过“Agent 化后训练”（Agentic Post-Training）和“路由治理”（Routing Harness）实现递归自我提升（Recursive Self-Improvement）的框架。该方法将大模型视作自主 Agent，在多元任务中自我设计训练策略、合成微调数据并动态评估自身的弱点。通过引入路由治理机制，系统能够动态评估和分流不同难度的任务，避免在自我博弈过程中的灾难性遗忘。模型可在多轮迭代中自主发现并修正错误，构建起一个完全闭环的学习网络。实验表明，这种自主闭环训练模式使模型在推理、编码和数学等复杂任务上实现了突破性的性能跨越。
* **潜在影响力**：
  为实现真正的“超级智能（ASI）”和无监督自我进化提供了一条极具前景的技术路径，展示了 Agent 化后训练作为下一代大模型范式的巨大潜力。

#### **2. [AuK Technical Report: An Open-Source Foundational Model for Speech Generation and Editing]**
* **论文链接**: https://huggingface.co/papers/2609.08936
* **研究机构/作者**: AuK 开源基础模型团队
* **核心痛点与创新点**：
  语音生成和编辑任务通常需要分离的、繁琐的模型，且在保持说话人音色一致性、控制语气语调以及实现精细化局部编辑方面存在较大局限性。本文推出了 AuK，一个完全开源的语音生成与编辑基座模型。AuK 采用统一的自回归与非自回归混合架构，能够同时处理高保真的文本转语音（TTS）和局部语音无缝修改任务。论文中引入了新型的音频 Codec 表征，有效平衡了音频重建质量和生成效率，实现了更低延迟的流式输出。通过海量多语种、多风格的数据进行训练，AuK 表现出极强的零样本（Zero-shot）说话人克隆能力和上下文控制力。此外，该模型不仅能从无到有地生成语音，还能允许用户在句子中间进行字、词级别的精确插入和替换，保持整体韵律自然连贯。
* **潜在影响力**：
  极大地推动了开源语音基础模型的发展，为有声书创作、虚拟人配音以及音频内容后期制作等工业级应用提供了高效、高质量的底层支撑。

#### **3. [Omni Interaction Agent Technical Report]**
* **论文链接**: https://huggingface.co/papers/2609.08977
* **研究机构/作者**: 多模态交互研究团队
* **核心痛点与创新点**：
  传统的 AI Agent 大多局限于单一的文本或简单的视觉模态，难以在复杂的现实世界中实现高实时、无缝的“全方位”（Omni）多模态交互。本技术报告推出了 Omni Interaction Agent，旨在构建一个能够同时处理视觉、语音和文本流式输入并输出协同动作的交互智能体。研究团队设计了一种端到端的多模态流式处理架构，消除了传统模块化串联造成的系统延迟和信息损耗。模型不仅能实时理解复杂的屏幕视觉和环境空间，还可以同时接收连续的语音指令。它能以极低的延迟生成相应的语音反馈和精确的动作操作。通过联合多模态后训练，智能体在复杂动态指令的执行和人机对话自然度上均达到了行业领先水平。
* **潜在影响力**：
  标志着多模态 Agent 向高度实时化、实用化迈出了关键一步，对智能助手、智能座舱和具身智能的交互层设计具有深远的指导意义。

#### **4. [Eliciting Weak-to-Strong Generalization with On-Policy Reverse Distillation]**
* **论文链接**: https://huggingface.co/papers/2609.08798
* **研究机构/作者**: AI 安全与对齐实验室
* **核心痛点与创新点**：
  “弱监督强模型”（Weak-to-Strong Generalization）是超大模型安全对齐的核心课题，但当前的对齐方法往往导致强模型盲目迎合弱监督者的错误。本文提出了一种全新的“同策略反向蒸馏”（On-Policy Reverse Distillation）方法来解决这一难题。该方法探索了如何利用较弱模型生成的监督信号，去引导并彻底释放强模型潜在的超强泛化能力。通过同策略的动态反馈调整，算法能敏锐检测出弱监督信号中的固有噪声。这样可以有效防止强模型过拟合于弱模型的缺陷或偏见，实现“青出于蓝而胜于蓝”。实验结果表明，该方法显著提升了强模型在未见任务上的泛化上限，使其表现超越了弱监督者的固有认知水平。
* **潜在影响力**：
  为超人工智能（Superalignment）的对齐安全提供了关键的技术工具，证明了即便在人类无法完全理解复杂任务的前提下，依然能确保更强 AI 系统的安全和泛化能力。

#### **5. [Miles v0.1: Production-Level Post-Training]**

* **研究机构/作者**: Miles 工程与研究团队

  从学术界的后训练（Post-Training）研究到工业界可生产（Production-Level）的部署之间存在巨大鸿沟，主要体现在对齐稳定性、安全红线控制与多任务性能的妥协。Miles v0.1 技术报告分享了面向生产环境的高效后训练系统级设计。团队提出了一整套标准化的偏好对齐（RLHF/DPO）管道，针对长文本生成和复杂指令遵循进行了极致优化。它引入了新型的动态样本加权和强化学习超参数自适应调整机制。这有效解决了后训练过程中常见的数据噪声敏感、模式崩溃以及遗忘问题。此外，Miles v0.1 特别强调了安全红线与通用模型能力的平衡，确保了模型在实际高并发业务上线时具备极高的鲁棒性。
* **潜在影响力**：
  为 AI 业界提供了一套透明、高效且可复制的生产级后训练最佳实践（Best Practice），有助于大幅缩短实验室模型到商业化落地之间的周期。

#### **6. [Mask Forcing: Improving Autoregressive Video Diffusion Distillation via Dual-Noise Masking Rollout]**
* **论文链接**: https://huggingface.co/papers/2609.09123
* **研究机构/作者**: 视频生成与扩散模型实验室
* **核心痛点与创新点**：
  传统的自回归视频生成和视频扩散模型的蒸馏过程极其耗时，且在长视频生成中容易出现严重的质量衰减和时序“漂移”问题。本文提出了 Mask Forcing，一种改进自回归视频扩散模型蒸馏的新方法。该方法创造性地在蒸馏训练阶段引入了双重噪声掩码展开（Dual-Noise Masking Rollout）机制。通过这种设计，模型在训练时不仅能学习去噪，还能学会主动纠正由前序生成帧带来的微小累积偏差。这种机制巧妙地打破了传统 Teacher-Forcing 方法导致的曝光偏差，极大提升了测试生成阶段的画质稳定性。最终，该方案实现了更短生成步数下的极高视频时序相干性和逻辑一致性。
* **潜在影响力**：
  显著降低了高质量视频扩散模型的推理开销，为长视频的超快速、低延迟、高保真生成开辟了新的技术路径。

#### **7. [Procedural Graphs: Self-Evolving Execution Structures for LLM Agents]**
* **论文链接**: https://huggingface.co/papers/2609.09153
* **研究机构/作者**: LLM 智能体架构课题组
* **核心痛点与创新点**：
  现有的 LLM Agent 系统通常采用固定的、静态的工作流，这限制了智能体在面对未知、突发和开放式复杂任务时的灵活应变能力。本研究提出了“程序化图”（Procedural Graphs）框架，赋予 Agent 自我演进执行结构的能力。该框架允许大语言模型 Agent 在执行任务的过程中，根据环境反馈动态修改、扩展甚至重新重构其自身的执行逻辑图。智能体可以即时创建新的任务分支节点，或者剪枝失效、无用的中间决策步骤。这种“图级别的自演进”将传统硬编码的工作流转变为模型可以自主掌控的动态策略。实验表明，该机制显著提升了 LLM Agent 在面对长链条、高不确定性阻碍任务时的最终执行成功率。
* **潜在影响力**：
  推动了 Agent 工作流从“静态配置”向“动态自适应”的跨越，为构建真正具备自主规划、容错和自我重构能力的通用 Agent 提供了全新范式。

#### **8. [Environments as Scaffold: Enriching Feedback to Bootstrap Self-Evolving Agents in Long-Horizon Tasks]**
* **论文链接**: https://huggingface.co/papers/2609.08404
* **研究机构/作者**: 强化学习与 Agent 联合研究小组
* **核心痛点与创新点**：
  在长程、高难度的复杂任务中，智能体由于缺乏密集的中间反馈，极难直接通过自我演进实现闭环的学习与能力攀升。本文提出了“环境即支架”（Environments as Scaffold）的反馈强化框架。该框架将复杂的长程任务转化为分层、渐进式的反馈支架，在智能体学习早期提供密集的目标提示与探索奖励。随着智能体自身决策能力的逐步提升，这些外部环境“支架”反馈会以动态衰减的方式被逐步撤去。这会倒逼智能体在后期稀疏奖励的环境中，学会独立进行深度的长期规划和复杂逻辑推理。该方法极大加速了 Agent 的引导过程，成功在无人类干预的冷启动状态下实现了自我迭代提升。
* **潜在影响力**：
  有效解决了具身智能和软件 Agent 在长任务中常见的“冷启动”和“探索困难”瓶颈，提供了一种高度自动化的强化学习演进方案。

#### **9. [CoVeR: Coverage-Based Token Pruning for Multi-View 3D Reasoning in VLMs]**
* **论文链接**: https://huggingface.co/papers/2609.08345
* **研究机构/作者**: 视觉空间智能研究室
* **核心痛点与创新点**：
  视觉语言模型（VLM）在进行多视角 3D 空间推理时，需要处理庞大的多角度图像序列。这导致了极高的计算开销和巨大的输入 Token 量，严重阻碍了其实时应用落地。本文引入了 CoVeR，一种基于覆盖率的高效多视角 3D 推理 Token 剪枝技术。CoVeR 通过计算不同视角图像块在空间几何上的“覆盖相似性”与语义相关度，动态识别并移除冗余视觉信息。在保留关键空间拓扑结构完整性的前提下，过滤掉大量重复且无关的背景 Token。实验表明，CoVeR 能够在不降低多视角 3D 问答精度的前提下，大幅减少 50% 以上的视觉 Token 计算量。
* **潜在影响力**：
  极大地降低了多模态 3D 重建与场景理解模型的硬件门槛，有利于将先进的空间推理 VLM 部署到边缘计算设备或移动机器人平台上。

#### **10. [TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model]**
* **论文链接**: https://huggingface.co/papers/2609.09158
* **研究机构/作者**: 具身智能与机器人学实验室
* **核心痛点与创新点**：
  双足人形机器人在杂乱复杂的实际场景中导航时，面临全身姿态协调困难和语义指令与底层动作对齐困难的双重挑战。为此，本文提出了 TANGO，一个面向人形机器人全身控制的视觉-语言-动作（VLA）模型。TANGO 将高层语义路径规划与底层物理动力学控制融合在统一的单体化大模型架构中。模型通过对障碍物的端到端语义理解和深度空间感知，直接生成关节控制动作。它可以动态调整机器人的手臂、躯干和双足关节，从而在通过极狭窄、多障碍的空间时依然保持动态完美平衡。这种高度一体化的控制决策有效避免了传统“规划-控制”分级架构中常见的动作延迟和累积误差。
* **潜在影响力**：
  显著提升了双足人形机器人在居家、工业仓储等复杂乱序环境下的实用避障与敏捷移动能力，树立了全身控制端到端 VLA 模型的新标杆。
