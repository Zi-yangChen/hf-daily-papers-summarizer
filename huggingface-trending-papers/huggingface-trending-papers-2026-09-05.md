#### **1. [Compile by Training: Turning Natural-Language Specifications into Local Neural Functions]** 
* **论文链接**: [https://huggingface.co/papers/2609.04199](https://huggingface.co/papers/2609.04199)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：将高层自然语言规范直接转化为在本地高效、确定运行的计算单元，一直是软件工程与 AI 结合的难题。当前大语言模型通常通过生成中间代码（如 Python）再执行，这带来了严重的安全、延迟和对齐隐患。本论文提出了一种名为“Compile by Training”的全新范式，旨在将自然语言规范直接“编译”并硬编码为本地的神经函数。研究团队通过构建大规模的“语言-函数映射”数据集，训练模型直接内化并输出可执行的局部计算图或专用神经权重，消除了对传统代码解释器的依赖。该方法还设计了特殊的约束机制，确保生成的局部函数在处理边界情况时具有极高的高保真度与鲁棒性。
* **潜在影响力**：该成果打破了传统编译器与深度学习之间的壁垒，为在边缘设备上动态、安全地生成本地微服务（Microservices）提供了新路径，有望重塑下一代软件开发工作流。

#### **4. [Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM]** 
* **链接**: [https://huggingface.co/papers/2609.04098](https://huggingface.co/papers/2609.04098)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：将数十亿参数的混合架构（含有 RNN/线性注意力部分）大语言模型量化到 4-bit（W4A4）时，循环网络部分往往会因为数值极其敏感而出现严重的崩溃或精度雪崩。本文深入探讨了 Gated DeltaNet（一种先进的线性循环架构）在面对 4-bit 极端量化时表现出超强鲁棒性的物理与数学机理。作者发现，Gated DeltaNet 的动态门控机制天然能够起到误差自纠正的作用，抑制了量化噪声在时间步上的累积。基于此，研究团队设计了针对硬件优化的 NVFP4（英伟达 4-bit 浮点）量化策略，在 27B 参数的混合模型上实现了“权重和激活值”的同时量化，在大幅压低显存的同时，几乎实现了无损的语言生成性能。
* **潜在影响力**：为大参数量混合模型（如 Linear Attention + Transformer）在消费级显卡和边缘设备上的高效部署铺平了道路，验证了新型循环网络架构在低算力场景下的独特优势。

#### **5. [Rethinking On-Policy Distillation of Large Language Models II: One Training Example]** 
* **链接**: [https://huggingface.co/papers/2609.04172](https://huggingface.co/papers/2609.04172)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：传统的同策略蒸馏（On-Policy Distillation）在对齐大语言模型时，需要依赖庞大且多样化的 Query 数据集来反复提示教师模型和学生模型，这带来了极高的计算成本和 API 开销。这篇论文提出了一个极具颠覆性的发现：仅仅使用“一个训练样本（One Training Example）”即可引导出极其成功的多任务在线蒸馏。作者通过理论分析表明，蒸馏的关键在于修正模型在局部动作空间上的偏离度，而非单纯记忆训练集。通过引入动态样本扰动与自适应反馈循环，系统围绕这唯一一个样本不断演化出复杂的探索路径，强迫模型在零样本场景下泛化，从而实现了极低的资源消耗与极佳的对齐性能。
* **潜在影响力**：颠覆了“大模型对齐需要海量高质量数据”的固有认知，对极小算力团队开展大模型私有化部署和在线对齐具有极高实用价值。

#### **7. [Scal3R: Learning Efficient Multi-Relative Pose Query for Scalable Online 3D Reconstruction]**

* **潜在影响力**：该算法将极大地优化 AR/VR 头显以及自动驾驶车辆在边缘端实时构建高精度三维地图的效率，有望成为新一代空间计算的基础构件。

#### **9. [Beyond Retrieval: Progressive Latent Memory Evolution for Streaming Video Understanding]**

* **潜在影响力**：为超长视频实时分析、智能车载监控及长时间跨度虚拟助手提供了极佳的落地方案。

* **核心痛点与创新点**：当前的视频生成大模型（如 Sora、Kling 等）可以画出极为逼真的画面，但在涉及复杂的“物理学交互”时经常露馅（例如水往高处流、物体发生碰撞时互相穿透）。现有评估基准往往只关注画面精美度。Principia 提出了一个专门测试视频大模型“关系物理学（Relational Physics）”的标准化评估框架。测试集涵盖了经典的刚体碰撞、重力自由落体、杠杆天平平衡、流体运动等多种具有严格因果物理规律的场景，并配以精细的语义标注。通过定量测量生成视频中物理现象的偏差，能够明确诊断出模型到底是在“背像素”，还是在“脑补物理引擎”。

#### **16. [Select, Compress, Reinvest: A Controlled Study of Visual-Token Allocation in Long-Video MLLMs]** 
* **链接**: [https://huggingface.co/papers/2609.03820](https://huggingface.co/papers/2609.03820)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：在多模态大模型处理长视频时，输入数百个视频帧会产生海量的“视觉 Token”，导致显存消耗呈二次方爆炸。现有的直接抽帧法或强行压缩全部 Token 的方法，要么丢失关键事件，要么把画面糊成一团。该研究针对 Token 分配开展了严格的控制变量实验，并提出了 SCR（Select, Compress, Reinvest）动态分配机制。算法会首先“选择（Select）”发生剧烈动作或转折的关键帧，对无关紧要的静态背景帧进行高比例“压缩（Compress）”，从而将省下来的宝贵 Token 资源“再投资（Reinvest）”到信息量极高、动作密集的黄金视频段，在有限的上下文窗口里保留了最核心的内容。
* **潜在影响力**：在硬资源（如单张消费级显卡）约束下，极大地释放了长视频多模态大模型的推理极限，使得在低成本设备上理解数小时的电影或监控视频成为可能。

#### **17. [Unlocking Lossless Speedups in LLMs via Discrete Diffusion]** 
* **链接**: [https://huggingface.co/papers/2609.04010](https://huggingface.co/papers/2609.04010)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：大语言模型（LLM）目前普遍采用逐字自回归（Autoregressive）的解码方式，这种单线程生成模式在推理时受到硬件带宽的极大限制。现有诸如投机采样（Speculative Decoding）的加速方法需要额外维护一个草稿模型，且往往会改变原始模型的输出概率分布。本文探讨了利用离散扩散（Discrete Diffusion）模型来实现“无损加速”的新颖机制。研究团队巧妙地将自回归网络与离散扩散采样器在架构上进行深度耦合。通过扩散模型的并行多 Token 预测和去噪修正能力，模型能一次性预测并输出多个 Token。最重要的是，论文在数学上保证了这种并行生成方式输出的概率分布与纯自回归方式完全一致。
* **潜在影响力**：这为打破自回归串行解码的致命物理瓶颈提供了高度可行且数学优雅的加速方案，有望显著提升工业界大模型在线推理的吞吐量并降低延迟。

#### **18. [SPARK: Input-Conditioned Sparse Activation Modulation for Frozen DiT-based Super-Resolution]** 
* **链接**: [https://huggingface.co/papers/2609.03813](https://huggingface.co/papers/2609.03813)
* **研究机构/作者**: 论文作者团队
* **核心痛点与创新点**：利用大型预训练 Diffusion Transformer（DiT）进行图像超分辨率微调时，如果对整个模型进行全量参数更新，不仅计算极其昂贵，而且容易破坏模型原本强大的生成先验（Prior），导致生成图失去自然质感。SPARK 论文提出了一种名为“输入条件控制的稀疏激活调制”的高效适配方案。该方法允许在保持原有大规模预训练 DiT 模型参数“完全冻结（Frozen）”的前提下进行超分训练。SPARK 设计了一个轻量级的调制支路，能根据低分辨率输入的特征，动态、稀疏地去激活和调制 DiT 内部的特征流动，以极低的微调算力实现高保真度的超分细节恢复。
* **潜在影响力**：为大型图像/视频 Transformer 模型进行 dense-prediction（稠密预测，如超分、去噪、分割）的高效轻量适配（PEFT）树立了新典范，对工业图像画质提升的落地具有很高的参考价值。
