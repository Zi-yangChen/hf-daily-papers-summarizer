#### **1. [DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression]**
- **论文链接**: https://huggingface.co/papers/2609.19969
- **研究机构/作者**: DeepSeek
- **核心痛点与创新点**: 在大语言模型（LLM）的超长上下文推理中，键值缓存（KV Cache）的显存占用是制约吞吐量和提高服务成本的最大瓶颈。传统压缩方法要么导致模型输出质量严重退化，要么无法在超低延迟约束下实现极高比例的压缩。DeepSeek-V4.1-Flash 通过引入创新的动态量化与稀疏剪枝联合优化算法，将 KV 缓存压缩推向了物理极限。该方法不仅针对 DeepSeek 独特的架构进行了底层算子重构，还引入了自适应重要性感知机制，确保关键上下文特征不丢失。实验表明，该技术在保持极高输出精度的同时，成倍降低了显存占用并显著提高了并发处理能力。
- **潜在影响力**: 该研究为百 K 级超长上下文的大模型商业化普及扫清了成本障碍，对云端大模型 API 的降本增效具有决定性的指导意义。

#### **2. [SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness]**

- **核心痛点与创新点**: 评估和部署先进的编码与推理 Agent 需要复杂的测试基准与交互环境（即 Agent Harness），然而手动设计这些测试环境不仅极其耗费人力，且难以跟上 Agent 自身能力的快速演进。SoL-Pi 提出了一个“递归扩展的自动研究闭环”框架来自动化这一过程。它将测试环境的设计抽象为一个元优化问题，通过 Agent 自主生成、测试并精炼评测协议。系统能够利用自反射（Self-Reflection）发现当前 Agent 的能力盲区，并自动构建出更具挑战性的动态测试沙盒。这种自我进化的机制极大减少了人工编写 Benchmark 的工作量，保证了评测的及时性与高保真度。
- **潜在影响力**: 本文打破了传统静态评测的局限，有望催生出能够自主寻找安全漏洞、自主升级测试沙盒的“自进化”AI 研发工作流。

#### **3. [When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation]**
- **链接**: https://huggingface.co/papers/2609.20511
- **研究机构/作者**: 未在元数据中提供（请参考原文）
- **核心痛点与创新点**: 在利用强化学习进行在线策略蒸馏（On-Policy Distillation）时，学生模型经常会出现严重的“长度膨胀”（Length Inflation）现象，即生成冗长且充满废话的回答以迎合奖励模型。本文深入揭示了该现象背后的理论机制：教师模型与学生模型在“终止符”（EOS Token）概率上的不一致。当终止信号错位时，策略梯度会产生不对称的惩罚，导致模型倾向于通过不断拉长文本来规避因提前结束带来的潜在惩罚。为此，作者提出了一种 EOS 不一致性数学公式，并设计了全新的终止符对齐正则化损失函数。这一改进在不牺牲模型生成质量的前提下，成功抑制了不必要的文本膨胀。
- **潜在影响力**: 解决了 RLHF/RLAIF 领域长期存在的“废话文学”顽疾，使更小、更高效的学生模型在蒸馏后保持简洁和高能效。

- **核心痛点与创新点**: 编程 Agent 极度依赖其运行和测试环境（Harness），但目前行业缺乏对不同环境配置（如工具集、沙盒隔离度、执行反馈粒度）如何影响 Agent 表现的系统性量化研究。本论文对编程 Agent 的 Harness 设计进行了全面的实证研究。作者系统评估了动作空间限制、实时编译反馈、状态化与无状态交互等维度对 Agent 在知名基准（如 SWE-bench）上成功率的影响。研究得出了许多反直觉的结论，例如：提供过分详尽的中间反馈有时反而会导致 Agent 陷入局部最优或产生过度拟合的调试死循环。基于此，团队提出了一套构建健壮、高效编程 Agent 运行环境的最佳实践指南。
- **潜在影响力**: 为软件工程领域（AI Coding）的开发者提供了宝贵的工程蓝图，对提高自主编程机器人的任务完成率具有直接指导作用。

#### **6. [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning]**
- **链接**: https://huggingface.co/papers/2609.20784
- **研究机构/作者**: 未在元数据中提供（请参考原文）
- **核心痛点与创新点**: 在线策略蒸馏（OPD）对于对齐高性能 Agent 至关重要，但在线调用庞大的教师模型会产生极高的计算和经济开销。过早停止蒸馏会导致性能退化，而过晚停止则造成算力严重浪费。RetireOPD 提出了一种创新的“自主退休”蒸馏机制。该系统通过实时监控学生模型与教师模型在特定任务域上的策略散度和动作分布对齐度，来动态评估学生的掌握程度。一旦检测到学生模型在某一子领域的提升曲线进入饱和期，便会自动对该部分的教师引导策略进行“退休”标记。这种动态调度机制在不影响最终 Agent 推理和任务执行能力的前提下，极大地节省了在线算力。
- **潜在影响力**: 大幅降低了训练企业级复杂 Agent 的算力门槛，使得中小型研发团队也能够负担得起长周期的在线策略蒸馏。

#### **8. [Video DeltaNet: A Video-Native Hybrid Attention for Livestream Video Generation]**

#### **9. [What Does Privileged Information Add to On-Policy Self-Distillation?]**
- **链接**: https://huggingface.co/papers/2609.20612
- **研究机构/作者**: 未在元数据中提供（请参考原文）
- **核心痛点与创新点**: 在策略自蒸馏（Self-Distillation）中，模型在不依赖外部更强教师的情况下进行自我提升，往往容易遭遇性能瓶颈。虽然在训练阶段引入“特权信息”（Privileged Information，如解题的草稿线索或环境真值状态）被认为有所帮助，但其背后的理论支撑和最优引入策略一直模糊不清。本论文对特权信息在自蒸馏中的作用进行了系统性的理论与实证剖析。研究发现，特权信息不仅仅是加速了收敛过程，更重要的是它通过平滑策略梯度的损失流，帮助学生模型跳出局部最优。作者据此提出了一种“渐进式特权信息衰减”的训练课程，使得模型在测试阶段脱离特权信息时仍能爆发出最强性能。
- **潜在影响力**: 为强化学习和复杂多步推理模型的课程设计（Curriculum Learning）提供了严谨的理论指导，有助于在推理成本不变的前提下逼出模型极限。

- **核心痛点与创新点**: 对现实世界中的关节运动物体（如笔记本电脑折叠、剪刀剪裁等）进行 3D 重构和关节建模极其困难，传统方法通常需要密集的单目多视角输入以及耗时的单场景逐个优化。FAMOS 提出了一种全新的前馈深度网络，可直接从极度稀疏的单视角或少视角观测中，一步预测出物体的 3D 关节结构和运动参数。它采用了一种能同时回归零件几何体、关节轴线、运动极限和当前开合状态的联合神经网络结构。通过在海量合成的关节物数据上进行预训练，该模型无需任何在线优化即可泛化到从未见过的全新物体类别上。

#### **11. [Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL]**
- **链接**: https://huggingface.co/papers/2609.20715
- **研究机构/作者**: 未在元数据中提供（请参考原文）
- **核心痛点与创新点**: 在强化学习训练中，为了简化状态表征，研究人员习惯于手动“遮蔽（Mask）”掉环境中与当前任务无关的背景或观测数据。然而，这种人工干预剥夺了 Agent 学习全局关联的机会，使得策略在外推到新场景时极其脆弱。本文大胆提出了“不要遮蔽环境”的观点，并引入了“观测监督（Observation Supervision）”方法。通过保留全量原始观测并结合自监督辅助任务（要求 Agent 预测或重建未屏蔽的环境动态），模型能够建立更丰满的世界关联。实验表明，未遮蔽的环境能够激活更高效、更有洞察力的探索行为，因为 Agent 可以利用背景中微妙的常识关联来预测未来的长期奖励。
- **潜在影响力**: 挑战了传统的 RL 特征工程直觉，推动了端到端自监督表示学习在复杂、嘈杂现实环境（如自动驾驶、野外机器人导航）中的应用。
