#### 1. [DanceOPD: On-Policy Generative Field Distillation](https://huggingface.co/papers/2606.27377)
*   **研究机构/作者**：ByteDance Seed
*   **核心痛点与创新点**：传统的图像生成模型需要统一文本生图（T2I）、局部编辑和全局编辑等多种能力，但这些能力在共同训练时往往相互冲突，导致性能退化。为了解决这一问题，论文提出了 DanceOPD，一种针对流匹配（Flow-matching）模型的同策略（on-policy）生成场蒸馏框架 [2606.27377]。该框架将每个样本路由至特定的能力场，并查询低噪声的学生引导状态 [2606.27377]。接着，它使用简单的速度均方误差目标来优化训练学生模型 [2606.27377]。通过将各个能力源定义为共享流状态空间上的速度场，学生模型可以从其自身滚出（rollout）状态下查询的场中进行学习 [2606.27377]。这种设计不仅能够融合专家能力，还能吸收无分类器引导（CFG）等操作定义的场 [2606.27377]。
*   **潜在影响力**：本研究为流匹配模型的多能力融合建立了一条切实可行的蒸馏路线 [2606.27377]，有望推动更高效、一体化的多功能图像编辑与生成模型落地。

#### 2. [ViQ: Text-Aligned Visual Quantized Representations at Any Resolution](https://huggingface.co/papers/2606.27313)
*   **研究机构/作者**：Tencent Hunyuan
*   **核心痛点与创新点**：现有的多模态模型在将图像表示为类似于文本的离散信号时，难以在低级细节和高级语义之间取得平衡 [2606.27313]。重建导向的表示通常缺乏语义，而强语义特征又会严重损失图像细节 [2606.27313]。论文提出了 ViQ，一种旨在平衡语义和细节的视觉量化表示框架 [2606.27313]。该框架支持原生分辨率输入，将其设计为文本对齐预训练和特征离散化两个阶段 [2606.27313]。在预训练阶段，利用预训练语言模型提供富含语义的监督，使视觉编码器具备高级语义并能处理原生分辨率 [2606.27313]。在离散化阶段，提出近端表示学习策略和位置感知头部量化机制，使其能灵活处理任意分辨率 [2606.27313]。
*   **潜在影响力**：提供了一种在保持高精度低级重建的同时，不输于连续特征的离散表示方法 [2606.27313]，可使多模态训练效率提升 20% - 70% [2606.27313]。

#### 3. [Qwen-Image-Agent: Bridging the Context Gap in Real-World Image Generation](https://huggingface.co/papers/2606.26907)
*   **研究机构/作者**：Qwen 团队
*   **核心痛点与创新点**：尽管文生图模型发展迅速，但在面对不明确、隐性或需要即时知识的真实用户请求时，往往面临“上下文差距”的挑战 [2606.26907]。为了弥合用户上下文与模型生成所需充足上下文之间的差距，论文提出了 Qwen-Image-Agent [2606.26907]。这是一个集成了规划、推理、搜索、记忆和反馈的统一智能体框架 [2606.26907]。框架将用户输入视为部分上下文，并通过两个核心模块来逐步构建充足的上下文 [2606.26907]。具体而言，“上下文感知规划”模块负责识别缺失信息并规划如何获取 [2606.26907]；“上下文接地”模块则通过搜索、推理、记忆和反馈来实际补充这些背景信息 [2606.26907]。
*   **潜在影响力**：推动了文生图系统向“主动交互与信息搜集”的智能体模式转变，显著提升了模型解决复杂、模糊生成任务的能力 [2606.26907]。

#### 4. [OPID: On-Policy Skill Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2606.26790)
*   **研究机构/作者**：Shuo Yang, Jinyang Wu 等
*   **核心痛点与创新点**：基于结果的强化学习为语言智能体提供了稳定的优化支撑，但稀疏的轨迹级奖励无法对中间决策进行有效指导 [2606.26790]。现有的技能蒸馏策略依赖外部记忆或检索特权上下文，维护成本高且容易与当前策略引发的状态分布不匹配 [2606.26790]。论文提出了 OPID（同策略技能蒸馏）框架，直接从已完成的同策略轨迹中提取技能监督 [2606.26790]。它将轨迹后视信息表示为分层技能：情节级技能捕获全局工作流，步骤级技能捕获关键时间步的局部决策 [2606.26790]。框架设计了关键优先路由机制，并在选定技能注入交互历史后，由旧策略在原上下文与技能增强上下文中进行重新评分 [2606.26790]。计算得出的对数概率偏移为策略提供了 Token 级的自蒸馏优势，并与结果优势结合进行策略优化 [2606.26790]。
*   **潜在影响力**：在 ALFWorld 和 WebShop 等复杂任务上表现出更高的样本效率和鲁棒性 [2606.26790]，为解决强化学习中的稀疏奖励与对齐偏差提供了新思路。

#### 5. [LISA: Likelihood Score Alignment for Visual-condition Controllable Generation](https://huggingface.co/papers/2606.27192)

*   **潜在影响力**：LISA 能够有效加速控制网络的训练收敛并提高最终的合成质量，且没有增加任何额外的推理成本 [2606.27192]，为受控生成模型的优化提供了极具性价比的新方案。

#### 9. [InfoKV: Information-Aware KV Cache Compression for Long Reasoning](https://huggingface.co/papers/2606.26875)
*   **研究机构/作者**：Jushi Kai, Zhuiri Xiao 等
*   **核心痛点与创新点**：在 LLM 长文本推理中，键值（KV）缓存的迅速膨胀是一个重大瓶颈 [2606.26875]。现有的 KV 缓存压缩方法主要依赖注意力权重来估算 Token 的重要性，但这忽略了预测不确定性等信息论信号 [2606.26875]。论文分析发现，注意力分数选出的 Token 主要影响临近上下文，而高预测不确定性（熵）的 Token 对遥远的未来上下文有显著更强的影响 [2606.26875]。据此，论文提出了 InfoKV 压缩框架 [2606.26875]。该框架将 Token 级别的预测不确定性与层级表征演化相结合，在推理过程中将计算出的熵得分与注意力得分进行融合，以此决定保留哪些 KV 缓存 [2606.26875]。
*   **潜在影响力**：在 Llama-3 和 DeepSeek-R1 等模型上的实验表明，该方法在长文本预填充和解码场景中均优于传统基于注意力的压缩方法 [2606.26875]，为高效的长文本推理开辟了新路径。

#### 10. [When Does Combining Language Models Help? A Co-Failure Ceiling on Routing, Voting, and Mixture-of-Agents Across 67 Frontier Models](https://huggingface.co/papers/2606.27288)
*   **研究机构/作者**：Kaikaku

*   **潜在影响力**：揭示了多模型集成系统的理论上限 [2606.27288]，为目前过度崇拜“多智能体混合/堆叠（MoA）”的研究趋势泼了一盆清醒的冷水，促使学界将精力转向更本质的单模型提升或超强路由器的开发上。
