#### 1. **[Ideas Have Genomes: Benchmarking Scientific Lineage Reasoning and Lineage-Grounded Idea Generation]**
- **论文链接**: [https://huggingface.co/papers/2607.08758](https://huggingface.co/papers/2607.08758)
- **研究机构/作者**: 国际前沿学术 AI 联合研究团队
- **核心痛点与创新点**：科学研究是一项具有强传承性的工作，然而现有的“AI 科学家”或 LLM 往往缺乏对科学思想演进脉络（学术血统/Lineage）的深层次理解。本文提出了“思想基因组”这一全新概念，并构建了首个旨在评估科学谱系推理和基于谱系的思想生成能力的基准测试。该基准侧重于评估模型能否精准识别前人研究的精髓，以及如何在已有学术思想的基础上进行逻辑自洽、具有新颖性的迭代创新。研究通过设计多层级的关联网络，测试了模型在海量科学文献中追溯灵感来源并生成后续研究方案的能力。实验揭示了当前主流大模型在处理复杂科学逻辑演进时的短板。
- **潜在影响力**：为 AI 辅助科研（AI for Science）提供了一套更严苛、更具启发性的评估标准，有助于推动真正能够自主继承和发展人类科学成果的“下一代 AI 科学家”系统的研发。

#### 2. **[UniClawBench: A Universal Benchmark for Proactive Agents on Real-World Tasks]**
- **论文链接**: [https://huggingface.co/papers/2607.08768](https://huggingface.co/papers/2607.08768)
- **研究机构/作者**: 主流 AI Agent 研究实验室
- **核心痛点与创新点**：现有的 AI Agent 评测集大多侧重于被动响应模式（即用户给出明确指令后执行），这无法真实反映 Agent 在面对现实复杂、模糊、动态变化环境时的“主动出击”（Proactive）能力。为此，本研究推出了 UniClawBench，一个专门评估主动型 Agent 在真实世界任务中表现的通用基准。该基准涵盖了动态任务环境、不完全信息状态以及长程规划等极具挑战的真实场景。在这些场景中，Agent 必须学会预测用户潜在需求，在没有显式指令的情况下识别隐性问题并主动寻找解决方案。论文还配套提出了一套涵盖主动性、安全性、执行效率等多维度的定量评估指标。
- **潜在影响力**：填补了主动型 Agent 定量评估领域的空白，将极大地促进具备前瞻性服务能力的具身智能、个人助理等软件 Agent 的产业落地。

#### 3. **[LongE2V: Long-Horizon Event-based Video Reconstruction, Prediction, and Frame Interpolation with Video Diffusion Models]**
- **论文链接**: [https://huggingface.co/papers/2607.08770](https://huggingface.co/papers/2607.08770)
- **研究机构/作者**: 计算机视觉与扩散模型联合团队
- **核心痛点与创新点**：事件相机因其高时间分辨率和超高动态范围在运动捕获中极具优势，但在长时程（Long-Horizon）的事件到视频重建、视频预测以及帧插值任务中，传统方法容易受到累积误差、伪影以及计算退化的困扰。LongE2V 引入了最先进的视频扩散模型（VDM），专门针对长时程基于事件的视频任务进行统一建模。该框架不仅能将稀疏的异步事件流重建为高质量视频，还能向前推导进行长时段的视频预测。通过设计独特的时间条件机制和特征融合算子，LongE2V 成功攻克了长视频生成中时空一致性难以保持的瓶颈。在面对高速运动和极端光照变化时，该系统表现出了极强的鲁棒性。
- **潜在影响力**：极大地拓宽了事件相机的应用物理边界，对高速机器人视觉、无人机避障导航以及夜间自动驾驶等关键工业落地场景具有重大的现实意义。

#### 4. **[Enhancing In-context Panoramic Generation via Geometric-aware Pretraining]**

- **研究机构/作者**: 计算机视觉与生成式 AI 研究团队
- **核心痛点与创新点**：上下文全景图生成要求模型根据给定的多视角或局部图像外推生成无缝且几何一致的 360 度全景图。然而，现有生成模型在跨视角过渡和深度一致性上常常出现拉伸、畸变或物理伪影。本文提出了一种创新的“几何感知预训练”框架，通过显式引入三维几何约束和空间变换算子，在预训练阶段就赋予了生成模型强大的空间结构感知。在实际生成过程中，模型能够理解相机的相对位姿变化，从而在像素级生成中维持严苛的几何对应关系。该方法在不牺牲图像生成多样性的前提下，显著提升了全景图的拼接精度与视觉连续性。
- **潜在影响力**：为 VR/AR 虚拟场景重建、元宇宙 3D 内容自动生成提供了一套高效、高保真的渲染与生成方案，缩短了二维图像到三维空间的感知鸿沟。

#### 5. **[DrugGen 2: A disease-aware language model for enhancing drug discovery]**

- **核心痛点与创新点**：传统的计算机辅助药物设计往往将分子生成与具体的疾病病理背景隔离开来，导致生成的化学分子虽然物理性质合规，但缺乏临床靶向性。DrugGen 2 通过引入一种全新的“疾病感知”语言模型机制，突破了这一瓶颈。它能够直接将多组学疾病特征（如基因表达谱、蛋白质相互作用网络）作为输入条件，并以此约束分子的自回归生成过程。模型在海量化学空间和疾病病理数据库上进行了大规模联合训练，深度学习了分子结构与特定疾病表型之间的深层映射规律。DrugGen 2 不仅能生成高亲和力的靶向配体，还能预测并优化分子的多靶点活性和药代动力学（ADMET）属性。
- **潜在影响力**：加速了从疾病生物标志物发现到靶点药物分子设计的一体化转化流程，显著降低了药物研发初期的临床前失败率。

#### 6. **[OpenCoF: Learning to Reason Through Video Generation]**
- **论文链接**: [https://huggingface.co/papers/2607.08763](https://huggingface.co/papers/2607.08763)
- **研究机构/作者**: 多模态大模型与物理世界模拟研究组
- **核心痛点与创新点**：现有的多模态大语言模型（MLLMs）在解决复杂的物理、空间和常识推理任务时，常常由于缺乏对物理规律的深度表征而产生推理幻觉。OpenCoF（Open Chain-of-Frame）提出了一个颠覆性的技术路线：让模型通过“生成视频”来学会物理推理。不同于传统的文本思维链（Chain of Thought），OpenCoF 要求模型在解答物理问题前，先预测并渲染出物理过程的变化帧序列。通过这一过程，模型被强制在其潜在表征空间中建立起对时间序列、物体交互以及物理规律（如重力、碰撞）的直观理解。实验表明，这种以视频生成为中介的推理模式，显著提高了模型在具身智能规划和复杂空间推理上的准确率。
- **潜在影响力**：为多模态推理开辟了全新的技术范式，表明生成式大模型不仅能用于视觉娱乐，更可以作为探索和重塑 AI 认知世界物理规律的强大工具。

#### 7. **[OPSD-V: On-Policy Self-Distillation for Post-Training Few-Step Autoregressive Video Generators]**
- **论文链接**: [https://huggingface.co/papers/2607.08766](https://huggingface.co/papers/2607.08766)
- **研究机构/作者**: 视频生成与模型轻量化蒸馏团队
- **核心痛点与创新点**：自回归（AR）视频生成模型因其高画质和时空连贯性而备受青睐，但其推理速度极慢，通常需要数十甚至数百步的自回归解码，严重制约了实时交互应用。OPSD-V 提出了一种专门针对自回归视频生成器的“策略内自我蒸馏”（On-Policy Self-Distillation）后训练（Post-Training）方法。该方法通过在模型自身的行为轨迹上进行强化学习与知识蒸馏，使模型学会了在极少的推理步骤（少至 4-8 步）内逼近完整轨迹的生成质量。OPSD-V 不仅保留了自回归模型原有的高动态表现力和时空连贯性，还避免了传统蒸馏过程中常见的模式崩溃（Mode Collapse）问题。
- **潜在影响力**：大幅降低了自回归视频模型的算力门槛，使得几步内（Few-step）的高质量实时视频生成、实时交互式视频应用（如游戏生成）成为可能。

#### 8. **[Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents]**
- **论文链接**: [https://huggingface.co/papers/2607.08716](https://huggingface.co/papers/2607.08716)
- **研究机构/作者**: AI Agent 记忆机制研究室
- **核心痛点与创新点**：在长时程（Long-Horizon）任务中，AI Agent 经常面临“信息过载”或“健忘”的尴尬，即在关键时刻由于注意力发散或向量检索不准，无法检索到很久以前获得的至关重要的上下文。本项目提出了“Proactive Memory Agent（主动记忆体）”架构。与传统的只在被调用时进行静态被动检索的向量数据库不同，该机制允许 Agent 在运行期间，根据当前任务的潜在演化方向主动筛选、整合和归档记忆。它设计了动态遗忘与选择性固化算法，让模型学会“在最需要的时候才精准唤醒记忆”。这种主动式的记忆整理机制极大地减轻了模型的上下文窗口负担和噪点干扰。
- **潜在影响力**：为构建能够持续运行数天、数周甚至数月的长期伴随式、协作式 AI Agent 奠定了高效、低开销的记忆架构基础。

#### 9. **[ARDY: Autoregressive Diffusion with Hybrid Representation for Interactive Human Motion Generation]**

- **潜在影响力**：在游戏开发、虚拟现实（Metaverse）、动画制作以及人机交互等领域有广泛应用前景，让 AI 生成角色动作更加自然生动。

#### 10. **[SAM-MT: Real-Time Interactive Multi-Target Video Segmentation]**

#### 11. **[A Quantized Native Runtime for On-Device Semantic Audio Generation]**

- **潜在影响力**：推动了离线、超低延迟的端侧实时语音交互和个性化音频生成技术的普及，对智能手机、智能座舱和可穿戴设备极具商业价值。

#### 12. **[Towards Mechanistically Understanding Why Memorized Knowledge Fails to Generalize in Large Language Model Finetuning]**
- **论文链接**: [https://huggingface.co/papers/2607.08393](https://huggingface.co/papers/2607.08393)
- **研究机构/作者**: LLM 机理解释性与微调机制研究团队
- **核心痛点与创新点**：在微调（Finetuning）LLM 时，经常会出现模型完美“背诵”了训练集知识（Memorization），但在稍微改变提问方式或进行泛化测试时却彻底失效的现象（Genralization Failure）。本文从机械可解释性（Mechanistic Interpretability）的视角出发，深入剖析了这一现象。研究者通过追踪微调过程中神经激活和权重变化路径，发现“背诵”的知识往往被耦合在极少数特定的注意力头或特定的非线性激活路径中，而没有融入到模型的全局语义表征网络中。由于这种局部的“捷径学习（Shortcut Learning）”，当输入发生微小扰动时，激活路径偏离，导致模型泛化失败。论文最后针对性地提出了一些微调约束正则项。
- **潜在影响力**：从理论和底层机制层面解释了大模型“死记硬背”的物理本质，为开发更具泛化能力、更鲁棒的微调算法提供了明确的指导思想。

#### 13. **[Wat3R: Underwater 3D Geometry Learning without Annotations]**

- **核心痛点与创新点**：水下由于光线折射、散射、悬浮颗粒物遮挡等物理特性，导致传统的三维几何学习与重建算法极易失效，且获取真实水下三维标注数据极其困难。Wat3R 提出了一种无需人工标注（Unsupervised/Self-supervised）的水下三维几何学习框架。该模型巧妙地利用了水下光照退化物理模型和多视角一致性原理，将水体介质带来的光学干扰解耦出来。通过引入自监督的深度估计与三维重建反馈回路，Wat3R 在嘈杂、浑浊的水下环境中，仍能鲁棒地重构出物体的三维精细几何结构。
- **潜在影响力**：对于水下考古、海洋生物监测以及水下机器人自主作业（如管道检修）具有极高的实用价值和学术启发。

#### 14. **[MulTTiPop: A Multitrack Transcription Dataset for Pop Music]**

- **核心痛点与创新点**：多轨音乐转谱（Multitrack Transcription）是音乐信息检索（MIR）的圣杯，但在流行音乐领域，由于多乐器混音极为繁复（人声、吉他、贝斯、鼓组交织），且缺乏高质量、带精确物理对齐标注的多轨数据集，制约了该技术的发展。MulTTiPop 填补了这一空白。它是一个专门针对流行音乐的大型多轨转谱数据集，包含了数千首高品质音轨及精确到音符级别的物理标注。数据集涵盖了多种流行音乐子风格，提供了乐器分离、MIDI 音符对齐、和弦标注等全套多维度真值。
- **潜在影响力**：为流行音乐的多乐器自动转谱、AI 混音和智能音乐教学研究树立了新的行业标准 benchmark。

#### 15. **[Native Video-Action Pretraining for Generalizable Robot Control]**
