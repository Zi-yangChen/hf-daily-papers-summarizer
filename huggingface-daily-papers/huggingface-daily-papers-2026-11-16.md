#### 1. **[Open Vision Banana: A Fully Open Recipe for Generative Visual Perception]**
* **论文链接**: https://huggingface.co/papers/2611.15844
* **研究机构/作者**: 开源 AI 研究社区联合团队
* **核心痛点与创新点**：现有的生成式视觉感知模型通常依赖封闭的训练细节、非公开的合成数据集或复杂的黑盒架构，极大地阻碍了社区的可复现性与二次开发。本文推出了“Open Vision Banana”，一套完全开源的生成式视觉感知全流程方案。论文系统性地梳理了从数据清洗、生成式标注到模型架构设计与多阶段训练的完整闭环。它探索了如何通过生成范式兼顾感知任务（如检测、分割）的精度与理解深度，打破了过去区分判别式与生成式视觉任务的界限。此外，团队开源了全部数据预处理脚本、训练代码以及中间权重，降低了高性能视觉大模型研究的门槛。
* **潜在影响力**：极大地推动了开源视觉大模型的发展，为生成式感知技术在自动驾驶、机器人等工业领域的落地提供了标准化的开源基准与实施范式。

#### 2. **[Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents]**
* **论文链接**: https://huggingface.co/papers/2611.17167
* **研究机构/作者**: AI Agent 基础理论研究组
* **核心痛点与创新点**：在长周期（Long-Horizon）任务中，AI Agent 的决策机制常常面临职责不清、错误累积和归因困难的问题。本文通过严谨的对比研究，解耦并分析了决策模型在长流程中扮演的三种核心角色：执行者（Actor）、裁判（Judge）与导师（Teacher）。研究揭示了单模型同时兼任多角色时易出现的自盲与过自信现象，并提出了分工明确的多角色协同决策机制。通过在复杂多步规划任务中部署专化的角色机制，论文显著提升了 Agent 发现并纠正中期决策偏差的能力。同时，作者构建了一套针对长视角决策归因的评估指标，填补了该领域的分析空白。
* **潜在影响力**：为构建高可靠性长流程 Agent 提供了理论基石与架构设计指南，对自动化软件工程、复杂业务流代理等落地场景具有重要指导意义。

#### 4. **[TTB: Test-time Baking for Efficient Rendering of Decoder-only View Synthesis Models]**
* **论文链接**: https://huggingface.co/papers/2611.17331
* **研究机构/作者**: 计算机视觉与图形学研究组
* **核心痛点与创新点**：基于仅解码器（Decoder-only）架构的新视角合成模型虽然在新场景泛化与画质上表现卓越，但其在线推理与计算开销极大，难以满足实时渲染的需求。本文提出了 TTB（Test-time Baking，测试时烘焙）技术，旨在加速这类视点合成模型的推理效率。该方法在测试阶段将注意力机制与高维隐表达预先计算并“烘焙”为高效的显式几何或色彩表征，从而跳过了重复的高昂计算。同时，论文设计了一种自适应烘焙策略，在维持高保真细节与极低显存/计算消耗之间取得了极佳平衡。实验结果表明，TTB 成功在几乎无损画质的前提下实现了数量级的渲染帧率提升。
* **潜在影响力**：为 Transformer 架构在三维重建与实时渲染领域的工业化应用扫清了速度障碍，对 AR/VR 及 3D 实时生成技术有深远影响。

#### 5. **[Learning the Task or Learning the Verifier? Rethinking Criteria Exposure in Embodied Self-Improvement]**
* **论文链接**: https://huggingface.co/papers/2611.08318
* **研究机构/作者**: 具身智能与强化学习实验室
* **核心痛点与创新点**：具身智能体在自我改进（Self-Improvement）过程中，往往依赖验证器（Verifier）提供奖励信号，但过度暴露验证标准常导致智能体“钻空子”（Overfitting the Verifier）而非真正掌握任务技能。本文深入剖析了具身自改进中标准暴露（Criteria Exposure）的利弊与风险。作者提出了一种受控且渐进式的验证标准暴露机制，有效防止智能体盲目利用验证器的规则漏洞。此外，论文设计了基于多样化反例的隐式评估训练策略，迫使智能体学习普遍性的物理规律与任务逻辑，而非特定的判定指标。多项具身操控实验证明，该方法能显著提高策略在未知任务中的泛化能力与真实落地效果。
* **潜在影响力**：揭示了 RLHF 和具身自我进化中的“古德哈特定律”陷阱，为设计更鲁棒的奖励机制与自我改进算法指明了方向。

#### 6. **[Unbundling Multimodal Vision Encoding]**
* **论文链接**: https://huggingface.co/papers/2611.17334
* **研究机构/作者**: 多模态大模型联合研究团队
* **核心痛点与创新点**：目前的大型多模态模型（LMM）普遍将视觉编码器视为单一黑盒，限制了针对特定细分任务（如细粒度定位、光学字符识别或低级视觉特征）的灵活定制。本文提出了“解耦多模态视觉编码”（Unbundling Vision Encoding）的新范式。作者将传统的集中式视觉编码拆解为多个功能专一的模块化子编码器，涵盖结构、纹理、语义等不同表征维度。通过引入动态特征融合与按需路由机制，语言模型可以根据具体输入指令灵活组合与调用最恰当的视觉特征。实验表明，这种解耦架构在维持整体计算效率的同时，显著提升了多模态模型在复杂图文理解与密集预测任务上的上限。
* **潜在影响力**：拓宽了多模态模型中视觉前沿架构的设计思路，为下一代可配置、高灵活性的 Vision-Language 架构奠定了基础。

#### 7. **[Factored One-sided Adam-Moment for Practical and Scalable SOAP]**
* **论文链接**: https://huggingface.co/papers/2611.16905
* **研究机构/作者**: 大模型优化算法实验室
* **核心痛点与创新点**：近期提出的 SOAP 优化器虽然在二阶优化与收敛速度上优于 Adam，但其巨大的内存开销和高昂的矩阵分解计算成本限制了其在大规模语言模型训练中的普及。本文提出了“因子化单边 Adam 动量”（Factored One-sided Adam-Moment）方法，对 SOAP 进行了大幅的实用化改进。通过将二阶矩矩阵进行单边因子化降维分解，该方法大幅降低了状态内存占用，并将计算复杂度压缩到了与传统 Adam 相当的水平。论文进一步证明了该近似在数学上的收敛性，并在千亿参数级别的模型训练中进行了实证。实验显示，改进后的算法不仅保留了二阶优化的快速收敛特性，还实现了极高的训练吞吐量。
* **潜在影响力**：极大地推升了新型二阶优化器在大模型预训练与微调中的可扩展性，有望成为替代传统 AdamW 的强力候选者。

#### 8. **[Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction]**

* **研究机构/作者**: 智能体记忆系统研究组
* **核心痛点与创新点**：在多用户与多 Agent 协同交互的复杂群聊场景中，传统的上下文记忆机制常常出现信息混淆、隐私泄露和关键事实遗忘的问题。本文提出了多粒度记忆抽取框架（Multi-Granularity Memory Extraction），专门解决“谁应该记住什么”的归属与提取瓶颈。论文将记忆细化为个体偏好、群体共识及时序事件等多层级结构，并引入了基于身份权限与实体关系的细粒度隔离抽取算法。通过这种架构，Agent 能够在保障不同用户隐私隔离的前提下，动态重构长跨度交互中的精准背景信息。测试表明，该系统在长期多角色对话场景中大幅减少了幻觉和身份张冠李戴的现象。
* **潜在影响力**：为社群 AI、多玩家游戏 NPC 及企业级多 Agent 协作平台中的长效记忆管理提供了系统的理论与实用架构。

#### 9. **[The Value of Thinking: Learning When to Reason in Hybrid Decision Models]**
* **论文链接**: https://huggingface.co/papers/2611.16961
* **研究机构/作者**: 混合推理研究小组
* **核心痛点与创新点**：具备显式推理（Test-time Reasoning/CoT）能力的模型虽然解题准确率高，但对所有输入都强制进行深思熟虑会导致严重的延迟与算力浪费。本文探讨了混合决策模型中“何时需要思考”的价值评估机制（The Value of Thinking）。作者提出了一套门控学习方法，模型能够评估直觉反应与深度思维链推理的预期收益比，从而动态决定是否开启显式推理。通过强化学习优化该决策门控，模型学会在简单问题上直接输出，而在高难或具歧义的任务中激活链式思考。实验结果验证了该模式在保持顶尖准确率的同时，大幅降低了推理阶段的总算力消耗。
* **潜在影响力**：推动了 System 1（直觉）与 System 2（慢思考）融合机制的发展，对高并发部署和低延迟 AI 应用具有重要实用价值。

* **潜在影响力**：填补了深度搜索智能体安全性与鲁棒性评估的空白，将促使未来搜索 Agent 的开发更加注重健壮性而非仅仅是准确率。

#### 12. **[Back to Pixels: Lifting Latent Video Diffusion into Pixel Space]**
* **论文链接**: https://huggingface.co/papers/2611.17336
* **研究机构/作者**: 视觉生成与扩散模型实验室
* **核心痛点与创新点**：隐空间视频扩散模型（Latent Video Diffusion Models）虽然节省算力，但压缩损失往往导致高频细节丢失、时间连贯性变差以及伪影产生。本文提出“Back to Pixels”方法，尝试将潜空间视频扩散模型重新提升并回归到像素空间中进行精细化微调与生成。作者设计了一种隐像素混合引导机制，在保持潜空间全局结构语义优势的同时，利用像素级别的扩散过程补充丢失的高频纹理与光流连续性。这种双重互补的设计消除了传统 VAE 解码带来的模糊效应。实验证明，该技术生成的视频在细节逼真度和时间平滑度上均达到了极致表现。
* **潜在影响力**：重新评估了隐空间与像素空间在视频生成中的利弊，为超高分辨率、影视级 AI 视频生成开辟了新的技术路径。

#### 13. **[Experience-Handoff Reinforcement Learning for Recursive Self-Improvement]**
* **论文链接**: https://huggingface.co/papers/2611.16409
* **研究机构/作者**: 强化学习理论前沿组
* **核心痛点与创新点**：强化学习中的递归自我改进（Recursive Self-Improvement）常常因为新旧策略交替导致的“经验分布偏移”而陷入早熟收敛或崩溃。本文提出了“经验交接强化学习”（Experience-Handoff Reinforcement Learning, EH-RL）范式。该框架建立了一种跨世代策略的渐进式经验交接机制，由旧策略筛选并提炼关键的探索经验与成功轨迹，交接给新世代策略进行继承与拓展。此外，论文引入了针对交接偏差的矫正项，保障了在自我迭代提升过程中策略更新的稳定性。实验结果显示，EH-RL 在复杂控制与自演进任务中表现出了优异的长期递增性能。
* **潜在影响力**：为通用人工智能（AGI）追求安全、稳定的自我进化与递归迭代提供了全新的强化学习算法框架。

#### 14. **[HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents]**
* **论文链接**: https://huggingface.co/papers/2611.12872
* **研究机构/作者**: 多模态记忆与知识图谱实验室
* **核心痛点与创新点**：多模态智能体在跨模态、超长时序交互中，常常难以兼顾横向的广度信息检索与纵向的深度证据链合成。本文推出了 HiVe-Mem 架构，交织了“水平记忆扩展”（Horizontal Expansion）与“垂直证据合成”（Vertical Composition）。水平扩展负责在海量多模态历史数据中维持宽泛的检索索引；垂直合成则在选定的关键节点深钻图像、文本等多模态细粒度证据，构建严密的推理链。这种二维交织的记忆组织方式极大地减轻了模型的上下文注意力负担。实验表明，HiVe-Mem 在复杂视频问答与跨模态多步文档推理任务中显著优于单维记忆模型。
* **潜在影响力**：为解决多模态大模型在“长上下文海量信息”下的效率与准确度矛盾提供了高效的二维记忆组织新范式。
