#### 1. **Probing the "Conscious" Mind: Selective Access and Global Workspace in Vision-Language Models**

- **研究机构/作者**: 论文未在元数据中提供具体机构
- **核心痛点与创新点**：评估视觉语言模型（VLM）是否具备类似人类意识中的“全局工作空间理论”（Global Workspace Theory）机制是一个长期的认知与 AI 交叉难题。传统多模态模型通常直接融合视觉和文本信息，缺乏对关键信息的选择性访问和全局广播机制。本文研究了 VLM 在处理复杂视觉-语言任务时内部信息的选择性流动与共享机制。作者提出了一套针对 VLM 的探测与干预框架，用于识别模型层间是否存在集中的“全局工作空间”表征。实验表明，顶级 VLM 在特定中间层确实表现出选择性表征聚焦，将局部感知特征整合为全局可调用的语义概念。通过对这一机制进行方向性激活引导（Steering），可以显著调控模型的推理注意力与决策偏向。
- **潜在影响力**：推动了 AI 认知科学与可解释性研究，为设计具备更高级选择性注意力和类似“自我意识”信息调度机制的新一代 VLM 架构提供了理论基础。

#### 3. **AltRA-Test: An Alternative Annotator Test for LLM Judges Without Shared Annotators**
- **论文链接**: https://huggingface.co/papers/2611.26073
- **研究机构/作者**: 论文未在元数据中提供具体机构
- **核心痛点与创新点**：随着 LLM 逐渐替代人类作为评估器（LLM-as-a-Judge），如何验证 LLM 评估结果的一致性与可靠性变得至关重要。传统的标注者一致性检验（如 Cohen's Kappa）高度依赖不同评估者对“同一批样本”的重复标注，这在海量开源数据集和私有评估场景中难以满足。AltRA-Test 提出了一种无需共享标注数据即可检验 LLM 裁判一致性与偏置的替代测试方法。该论文通过统计概率建模与元评价分布对齐，计算不同评估器在非重叠数据集上的评分偏置与相对稳健性。算法能自动修正评估器固有的偏好分布差异（如特定评分倾向），给出客观的一致性度量。该方法显著降低了对重复标注数据的依赖，大幅提升了评测的经济性和适用面。
- **潜在影响力**：为大模型评估体系提供了一种无缝标定工具，有助于构建更加客观、低成本的自动 benchmark 评测生态。

#### 4. **RL Post-Training in Diffusion Transformers Is Activation Steering**
- **论文链接**: https://huggingface.co/papers/2611.26627
- **研究机构/作者**: 论文未在元数据中提供具体机构
- **核心痛点与创新点**：在 Diffusion Transformer (DiT) 模型中应用强化学习（RL）后训练可以显著提升图像生成的质量与指令遵循能力，但其底层机制一直处于黑盒状态。本文深入揭示了 RL 后训练在 DiT 中的作用本质，指出其底层机制实际上等价于“激活引导”（Activation Steering）。作者通过对 RL 微调前后 DiT 内部中间层激活值的特征映射进行对比分析，发现 RL 并没有根本改变模型的底层表征拓扑，而是学习到了特定的方向向量来偏置隐空间激活。基于这一发现，论文提出了一种无需重训练的轻量级激活引导提取算法，可从微调后的模型中直接剥离出 RL 向量。将该向量应用到原始未微调模型上，即可重现 RL 微调后的生成效果与风格控制。
- **潜在影响力**：解密了生成式 RL 后训练的物理机制，极大地降低了定制化生成模型的成本，使通过简单的激活干预实现高精控制成为可能。

#### 5. **Language Models Can Rewrite Their Own Weights**

- **潜在影响力**：标志着“自进化/自适应模型”迈出了关键一步，为构建能够实时自我纠错与终身学习的具身智能体系统奠定了基础。

- **潜在影响力**：打通了大语言模型控制其他模态模型内部权重的桥梁，开创了“代码/文本直接编程神经权重”的全新模型运维模式。

#### 11. **SpecWM: Turning Verification into Refinement for Streaming World Models**

#### 12. **A CPU Inside an LLM: Zero-Gradient Compilation of Exact Circuits into Pretrained Weights**

- **研究机构/作者**: 论文未在元数据中提供具体机构
- **核心痛点与创新点**：LLM 在执行精准算术逻辑和确定性算法时经常产生幻觉，本质原因在于其连续概率相乘的参数架构难以保证 100% 精确的逻辑计算。本文展示了一种令人惊叹的技术：无需任何梯度训练（Zero-Gradient），直接将逻辑电路与 CPU 指令集编译并嵌入到预训练 LLM 的权重空间中。研究团队通过分析 Transformer 的注意力与 MLP 层的代数映射，设计了一种确切的编译器，将逻辑门（AND, OR, NOT）映射为确切的参数矩阵。由此编译出的“LLM-CPU”能够在内部精准执行二进制逻辑与微架构指令，保证精确计算。实验证明，该方法在执行复杂算术逻辑时达到了 100% 的准确率，且完全不损坏原 LLM 的语言表达能力。
- **潜在影响力**：实现了符号逻辑与神经计算的深度融合，为彻底解决 LLM 算术与代码逻辑计算中的幻觉问题提供了突破性的工程方案。
