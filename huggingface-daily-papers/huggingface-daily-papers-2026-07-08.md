#### 1. **[OmniOpt: Taxonomy, Geometry, and Benchmarking of Modern Optimizers]** 
(附带论文链接: https://huggingface.co/papers/2607.04033)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：当前深度学习领域涌现出繁多的优化器（如 Adam, SGD, Lion 等），且其设计空间极其复杂，业界一直缺乏系统性的分类学以及跨多元化任务的统一大规模评测，这导致研究人员在面对新任务时难以选择最佳优化器。本文提出了 **OmniOpt**，这是对现代优化器的系统分类法和广泛的几何及基准测试研究。研究团队对数百个优化器进行了科学分类，并深入探讨了它们在损失平面（Loss Landscape）上的几何表现。他们构建了一个庞大的评测基准，涵盖了自然语言处理、计算机视觉到强化学习等多元化任务。通过标准化的实验，论文揭示了不同优化器在不同超参数配置下的鲁棒性和收敛行为，并给出了实用的选择指南与经验公式。
- **潜在影响力**：能够显著规范未来优化器的设计与评估，帮助从业者在没有海量试错成本的情况下，快速定位最适合特定模型的训练算法与超参数。

#### 2. **[MANCE: Manifold Aware Concept Erasure]** 
(附带论文链接: https://huggingface.co/papers/2607.03973)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：神经网络在训练中可能会无意间学习到有害、敏感或受版权保护的概念，如何在不彻底重训模型的前提下，安全、彻底地“擦除”这些特定概念是一大难题。现有的概念擦除方法往往会破坏模型在非相关概念上的通用表示，或者擦除得不够彻底、容易被逆向破解。本文提出了 **MANCE**（流形感知概念擦除），这是一种保留数据几何流形结构的新型概念擦除技术。它通过在表示空间中约束特征投影，确保擦除过程仅作用于特定流形方向，而不会破坏原本正常的特征几何关系。该方法在图像分类、文本表示和扩散模型等多种任务上进行了测试，展示了极佳的选择性擦除能力，且对模型原本性能几乎无损。
- **潜在影响力**：为模型安全、隐私保护以及大模型的版权合规（如擦除特定画家风格或敏感文本概念）提供了一种高效、无损的模型编辑新范式。

#### 3. **[EVA-Client: A Unified Data Collection, Inference, and Deployment Framework for Embodied Policies on Real Robots]**

- **潜在影响力**：极大地降低了具身智能研究的硬件和软件门槛，加速了机器人策略从仿真环境向现实世界部署（Sim-to-Real）的工业化落地。

#### 4. **[InternVLA-A1.5: Unifying Understanding, Latent Foresight, and Action for Compositional Generalization]** 
(附带论文链接: https://huggingface.co/papers/2607.04988)
- **研究机构/作者**：上海人工智能实验室 (Shanghai AI Lab) 等
- **核心痛点与创新点**：传统的视觉-语言-动作（VLA）模型在面对新颖或复杂的组合场景（Compositional Scenarios）时，往往缺乏对物理世界的长程规划和预见能力（Foresight），导致其做出的动作缺乏泛化性。**InternVLA-A1.5** 提出了一个将视觉理解、潜在未来预测（Latent Foresight）和动作生成统一在同一个大模型框架下的全新方案。模型不仅要学习“当前该做什么”，还要在潜在表征空间中预测“做出该动作后物理世界会变成什么样”。通过这种自监督的未来视界预测，模型建立起了对物理规律的深刻直觉。在多项组合泛化基准测试中，该模型表现出远超传统 VLA 模型的鲁棒性与决策合理性。
- **潜在影响力**：推动了新一代具身智能模型朝“世界模型+动作规划”的方向演进，增强了机器人在复杂未知环境中的自主决策和故障恢复能力。

#### 5. **[KVpop -- Key-Value Cache Compression with Predictive Online Pruning]** 
(附带论文链接: https://huggingface.co/papers/2607.05061)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：大语言模型在处理超长文本（Long Context）推理时，KV 缓存（Key-Value Cache）的显存占用会急剧飙升，成为制约并发吞吐量和硬件成本的最大瓶颈。现有的 KV 缓存剪枝方法往往是静态的或单纯基于启发式规则，极易导致长文本注意力机制的精度严重受损。本文提出了 **KVpop**，一种基于在线预测性剪枝（Predictive Online Pruning）的 KV 缓存压缩技术。它在推理过程中利用轻量级的预测机制，动态且实时地识别出哪些 KV 标记在接下来的生成步骤中“最受欢迎”（即最可能被注意力机制高频关注）。对于预测为低频或无关的 KV 状态，算法进行即时剪枝或驱逐，从而在保持超高生成精度的同时，极大地降低了显存开销。
- **潜在影响力**：为超长上下文（如十万甚至百万 Token 级别）的低成本、高并发 LLM 推理部署提供了极具吸引力的工程与算法级解决方案。

#### 6. **[Multi-Turn Agentic Scientific Literature Search via Workflow Induction]** 
(附带论文链接: https://huggingface.co/papers/2607.00597)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：面对极其庞大且高度专业化的科学文献库，传统的单次检索（Single-turn Retrieval）或简单的对话 Agent 很难进行深度、系统性的文献综述，容易出现信息遗漏或检索路径偏离等问题。本文提出了一种通过工作流归纳（Workflow Induction）来实现的**多轮 Agent 科学文献搜索系统**。该方法并不让 Agent 进行盲目的自由探索，而是先从人类学术专家的文献调研习惯中，利用大模型自动归纳出结构化的多轮工作流（如“背景搜索 - 交叉引用过滤 - 关键方法提取 - 对比分析”）。Agent 在该工作流的引导下，通过多轮迭代和自我修正，进行有目的的、深度的文献检索与合成。
- **潜在影响力**：显著提升了学术搜索 Agent 的专业性与系统性，为科研人员提供了一个能够自动撰写高质量文献综述、高效追踪技术路线的智能助手。

#### 7. **[Do All Visual Tokens Matter Equally? Object-Evidence Preserving Token Merging for Vision-Language Retrieval]** 
(附带论文链接: https://huggingface.co/papers/2607.04605)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：视觉-语言检索（VLR）模型在处理高分辨率图像时，视觉 Token 的数量极其庞大，带来了巨大的计算开销。然而，并不是图像中的所有区域（如背景、天空等无信息区域）对跨模态对齐都有同等贡献。本文提出了 **OE-ToMe**（目标证据保留的 Token 合并方法）。该方法在推理或微调过程中，动态评估每个视觉 Token 是否包含对文本检索有决定性贡献的“物体证据”（Object-Evidence）。通过合并或修剪那些属于冗余背景的 Token，同时完好保留蕴含关键语义和物体信息的 Token，模型在几乎不损失检索精度的前提下，实现了视觉端特征计算的大幅加速。
- **潜在影响力**：优化了图文多模态大模型的计算效率，非常适合在资源受限或需要实时处理海量视频/图像数据的检索系统和边缘设备上部署。

#### 8. **[dOPSD: On-Policy Self-Distillation for Diffusion Language Models]** 
(附带论文链接: https://huggingface.co/papers/2607.04428)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：扩散语言模型（Diffusion Language Models）在离散文本生成领域展现出优秀的非自回归生成能力，但为了达到高文本质量，通常需要多达数十步甚至上百步的反向去噪步骤，导致推理速度极慢，难以实用。本文提出了 **dOPSD**（基于同策略自蒸馏的扩散语言模型方法）。该方法利用同策略（On-Policy）的数据生成，让模型自身生成的离散轨迹作为监督信号，将多步扩散过程中的知识自我蒸馏到更少步骤的精简模型中。通过精心设计的自蒸馏损失函数，该方法能够在仅需极少（例如 4-8 步）去噪步骤的情况下，依然保持甚至超过原始长步数扩散模型的生成多样性与困惑度（Perplexity）。
- **潜在影响力**：加速了扩散模型在自然语言处理领域的实用化进程，使得高质量的非自回归文本生成在计算效率上能与传统的自回归 LLM 展开竞争。

#### 9. **[Perceptual Flow Matching for Few-Step Generative Modeling]** 
(附带论文链接: https://huggingface.co/papers/2607.03524)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：流匹配（Flow Matching）是近年来兴起的能够替代扩散模型的高效生成范式，但在极少推理步数（Few-Step）下，生成的图像细节往往会出现模糊或伪影，缺乏感知层面的真实感。本文提出了**感知流匹配（Perceptual Flow Matching, PFM）**。该方法在流匹配的训练和蒸馏阶段，引入了基于人类感知质量的损失函数（如感知重构损失和对抗性引导）。它通过直接优化流轨迹（Flow Trajectories），使其在少量步数采样时，也能优先保留视觉最敏感的边缘、纹理和全局语义特征。实验表明，PFM 在 1 步到 4 步采样下生成的图像质量远超传统流匹配。
- **潜在影响力**：极大地降低了高质量图像生成、视频生成任务的算力门槛，使得超高速的实时高保真图像生成走向实用。

#### 10. **[EdgeBench: Unveiling Scaling Laws of Learning from Real-World Environments]** 
(附带论文链接: https://huggingface.co/papers/2607.05155)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：目前大多数强化学习（RL）和智能体的缩放定律（Scaling Laws）研究都是在高度抽象和理想化的模拟环境（如 Atari 游戏、Grid World）中进行的，对于包含现实世界各种不确定性和复杂边缘情况（Edge Cases）的物理环境中的缩放规律依然缺乏系统认识。为此，本文推出了 **EdgeBench**，这是首个专门用于揭示智能体在“真实物理世界及充满噪声的环境”中学习时缩放定律的基准测试集。研究者系统地探索了模型参数量、数据多样性、训练步数以及环境随机性（如传感器噪声、物理摩擦变化）之间的复杂互动。研究发现，在真实环境中，简单的增加参数量并不能等比例提升泛化能力，数据本身的“边缘状态丰富度”起到了更为主导的作用。
- **潜在影响力**：为机器人具身智能、自动驾驶等实体 AI 系统的模型设计和数据收集策略提供了科学的理论支撑，指导研究者在真实世界中如何最经济高效地分配计算与标注资源。

#### 12. **[MV-Forcing: Long Multi-View Video Generation via 4D-Grounded Spatio-Temporal Self-Forcing]**

#### 13. **[SeKV: Resolution-Adaptive KV Cache with Hierarchical Semantic Memory for Long-Context LLM Inference]** 
(附带论文链接: https://huggingface.co/papers/2606.31145)
- **研究机构/作者**：详见论文链接
- **核心痛点与创新点**：在超长文本推理中，仅仅通过硬性的 KV 缓存截断或均匀压缩往往会破坏文本内在的层级语义结构（如句子、段落层级的连贯性），从而导致 LLM 无法正确回答细节问题。本文提出了 **SeKV**，一种分辨率自适应（Resolution-Adaptive）的 KV 缓存优化方法，该方法融合了层级语义内存（Hierarchical Semantic Memory）机制。SeKV 可以根据当前输入的文本内容语义密度，动态调整 KV 缓存的压缩分辨率：对于信息密度极高的关键句段采用高分辨率（保留几乎全部 KV 细节），对于冗余或过渡性句段则将其归纳、合并为低分辨率的层级语义节点。这种基于语义结构的管理方式实现了按需分配内存。
- **潜在影响力**：为超长文本（如整本书、全代码库）的精准阅读理解推理提供了一种更符合人类认知模式、效率极高的 KV 管理策略。

- **潜在影响力**：提升了医学影像报告自动生成的严谨度与跨周期对比的准确性，对于辅助临床医生追踪重症或慢性病患者的影像学进展具有重大现实意义。
